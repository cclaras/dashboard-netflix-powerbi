# dashboard-netflix-powerbi
# Netflix Movies and TV Shows Data Analysis

Este repositório contém um dashboard interativo desenvolvido no Power BI para analisar o catálogo, a popularidade e as avaliações de títulos da Netflix lançados entre 2010 e 2026.
Os dados utilizados neste projeto foram extraídos do dataset "Netflix Movies and TV Shows Data Analysis" disponível no Kaggle.


# Principais Insights do Dashboard

* Volume do Catálogo: Total de **2.175 mil** títulos analisados no período de 16 anos.
* Predomínio de Idioma: A língua **Inglesa (en)** domina amplamente o catálogo, representando 90,16% dos títulos (1,97 Mil).
* Gênero mais Popular: Ação (Action) é o gênero com a maior soma de popularidade disparada, seguido por Animação e Drama.
* Melhores Avaliações: Apesar de Ação ser o mais popular, o gênero Drama lidera o ranking de melhores avaliações médias pelos usuários.
* Tendência de Lançamentos: O volume de produções apresentou um crescimento consistente com pico entre 2015 e 2018, seguido por uma redução nos anos posteriores.


# Tecnologias Utilizadas

* Power BI Desktop (Construção dos visuais e modelagem)
* Kaggle (Fonte dos dados brutos)
